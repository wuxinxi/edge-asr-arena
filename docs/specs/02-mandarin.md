# 02 · 中文普通话识别

> 维度编号：ZH-CLEAN | 优先级：P0

## 背景

所有模型的基线能力。在安静近场、标准普通话发音下测 CER，作为其他更困难维度的对照基准。这个维度的 CER 低不代表模型在噪声/方言下也好，但这个维度的 CER 高一定说明模型基础能力有问题。

## 测试集要求

- **音频数量**：≥ 50 条
- **录音条件**：安静室内，手机/麦克风距嘴 15-30cm，16kHz 单声道 WAV
- **说话人**：至少 5 人（男女各半，年龄 25-40），标准普通话无明显口音
- **内容覆盖**：
  - 短句（< 5 字）："你好"、"打开灯"
  - 日常对话："明天下午三点开会，别迟到"
  - 新闻播报风格："今天天气晴转多云，气温 22 到 28 度"
  - 长段落（> 100 字）：一段产品介绍或故事
- **时长分布**：短句 1-3 秒占 30%，中等句 3-10 秒占 50%，长段落 10-60 秒占 20%
- **每条音频配参考转写**：人工听写，标注是否含数字、标点

## 评测指标

| 指标 | 说明 |
| --- | --- |
| CER | 主指标 |
| S/D/I 分解 | 特别关注 insertion（幻觉） |
| RTF | 离线速度 |
| 内存峰值 | |

## 通过参考（非正式目标）

- 理想 CER < 5%（商用可用）
- CER 5-10%（个人可用，需人工校对）
- CER > 15%（不建议用于中文场景）

## 注意事项

- 同一句话让 3 个说话人各录一遍，观察说话人方差
- 不要用新闻联播级别的标准播音——真实用户说话没那么标准，但这个维度就是测"干净条件下的天花板"
- 长段落单独统计，因为长音频容易出现重复输出或提前截断
