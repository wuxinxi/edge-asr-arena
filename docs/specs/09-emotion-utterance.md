# 09 · 情感与特殊发音

> 维度编号：EMOTION | 优先级：P1

## 背景

标准发音的句子大家都能转，但人说话是有情绪的。笑着说话、哭着说话、低声耳语、扯着嗓子喊、咳嗽打断——这些是真实语音助手场景里经常出现但容易被测试集忽略的情况。

SenseVoice 额外输出情感标签和音频事件，这个维度正好测它的这一差异化能力。

## 测试集要求

- **音频数量**：≥ 30 条
- **类型覆盖**：

| 类型 | 示例场景 | 条数 |
| --- | --- | --- |
| 笑腔说话 | 边笑边说"哈哈哈这个真的太好笑了" | 5 |
| 哭腔/悲伤 | "我真的做不到啊" | 3 |
| 愤怒/激动 | "你怎么能这样！"（大声） | 3 |
| 低语/耳语 | 小声说"别告诉他" | 3 |
| 喊/大声 | 远距喊"快来人啊" | 3 |
| 咳嗽/清嗓打断 | "明天——咳——下午开会" | 3 |
| 叹气/嗯啊语气词 | "嗯…让我想想…啊对了" | 3 |
| 快速连读 | 语速明显快于正常 | 3 |
| 拖长音/犹豫 | "那个……我觉得吧……可能……" | 3 |

- **录音人**：至少 2 人能自然表现这些情绪
- **参考转写**：写清楚说的内容，标注情感类型

## 评测指标

| 指标 | 说明 |
| --- | --- |
| CER | 情感状态下的转写准确率 |
| 情感标签正确率 | SenseVoice 是否正确输出了 happy/sad/angry/neutral |
| 音频事件检测 | 是否正确识别 cough/laughter/applause |
| 端点截断率 | 低语/叹气是否被 VAD 截断或完全漏识别 |

## 特别观察项

- Whisper 对哭腔/笑腔的抗干扰与抗造表现
- SenseVoice 的情感标签是否准确（这是它的卖点）
- 耳语场景：声压级极低，接近噪声门限
- 咳嗽打断：VAD 是否会把一句话切散

## 注意事项

- 不要演得太夸张——要模拟真实情绪强度
- 低语场景同时考验前端 VAD 和模型声学模型
- 这个维度的 CER 预期会比干净基线高，关注的是**哪个模型退化最少**
- 情感标签和转写准确率是两个独立指标，分开统计
