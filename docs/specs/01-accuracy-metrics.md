# 01 · 准确率基准与指标口径

> 维度编号：ACC-METRIC | 优先级：P0（所有其他维度的基础）

## 背景

ASR 评测的核心是"转写得准不准"，但"准"的定义本身需要先对齐。不同模型输出格式差异极大：有的带标点，有的不带；有的输出"三点"，有的输出"3点"；有的全角字符，有的半角。如果不归一化，CER/WER 数值会被格式差异污染，无法横向比较。

本维度不评测具体场景，而是定义**所有其他维度共用的指标计算规则**。

## 评测内容

### 1.1 文本归一化规则

在计算 CER/WER 之前，对 hypothesis（模型输出）和 reference（参考转写）统一做以下处理：

| 规则 | 示例 | 默认开启 |
| --- | --- | --- |
| 全角→半角数字/字母 | "ＡＢＣ１２３" → "abc123" | 是 |
| 连续空白合并 | "你好   世界" → "你好 世界" | 是 |
| 首尾空白去除 | " 你好 " → "你好" | 是 |
| 中英文标点统一 | "你好。" vs "你好." → 统一为中文标点 | 是 |
| 英文大小写统一 | "Hello" vs "hello" | 可配置，默认关（保留原文展示） |
| 数字口语→阿拉伯数字 | "三点" → "3点" | 可配置，默认关 |
| 语气词剥离 | "嗯，你好" → "你好" | 可配置，默认关 |
| 繁简转换 | "語音" → "语音" | 可配置，默认关 |

**关键决策**：归一化规则本身要在批次记录中保存，不同规则跑出的 CER 不可直接比较。

### 1.2 CER 与 WER 定义

- **CER（Character Error Rate）**：中文场景按字符切分
  - CER = (S + D + I) / N_ref_chars
  - S=替换数，D=删除数，I=插入数
- **WER（Word Error Rate）**：英文场景按空格分词
  - WER = (S + D + I) / N_ref_words
- 中文按字、英文按词，**不混用**。中英混读场景（spec 04）单独定义混合切分策略。

### 1.3 错误分解

每条转写必须输出三类错误的计数：
- **Substitution（替换）**：参考是"订单"，输出是"登单"
- **Deletion（删除）**：参考有"请"，输出漏了
- **Insertion（插入）**：参考没有，输出多了（幻觉）

这三类错误的业务含义完全不同：删除=漏信息，插入=幻觉，替换=错信息。平台必须分别展示，不能只给一个总 CER。

### 1.4 对齐方式

使用编辑距离对齐（Levenshtein），中文按字、英文按词。不使用基于发音的对齐（那是 TTS 的事）。

## 测试集要求

- 本维度不需要独立音频集
- 用 spec 02（普通话）的音频，在不同归一化开关下跑两遍，对比 CER 差异
- 至少覆盖 20 条普通话音频，观察归一化对结果的影响幅度

## 交付物

- `backend/app/core/metrics.py`：实现归一化 + CER/WER 计算 + 错误分解
- 前端"指标口径"说明页：展示当前批次用了哪些归一化规则
- 一份归一化敏感性报告：同批音频在"严格/宽松"两种规则下的 CER 差异

## 注意事项

- CER < 0 不可能；CER > 1 是可能的（插入错误远超参考长度），不要截断
- 参考转写本身可能有错。平台提供"修正参考文本"功能，修正后重算指标，保留原始版本
- 不要把 CER 平均后再做跨维度比较——不同维度音频难度不同
