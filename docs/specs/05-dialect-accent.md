# 05 · 方言与地域口音

> 维度编号：DIALECT | 优先级：P0

## 背景

用户明确要求方言独立成维度。这是 Whisper 系列的弱项（99 语言但中文方言覆盖有限），却是 Qwen3-ASR 的卖点（22 种中文方言）和 SenseVoice 的支持范围（含粤语）。

方言和口音要分开：
- **方言**：粤语、四川话、上海话——有独立语法和词汇，不是普通话的变体
- **口音**：东北口音、四川口音、粤语口音说普通话——语法仍是普通话，发音有变异

## 测试集要求

- **音频数量**：≥ 40 条
- **方言覆盖**（每类至少 5 条）：
  - 粤语（广州话）：Qwen3-ASR、SenseVoice 标称支持
  - 四川话/重庆话：Qwen3-ASR 22 方言覆盖
  - 上海话/吴语：Qwen3-ASR 覆盖
  - 东北口音说普通话：口音，不是方言
  - 川渝口音说普通话：口音
- **录音人**：每类方言至少 1 位母语者
- **内容**：日常对话为主，不要求书面语
- **参考转写**：用普通话书面语转写（目标是"方言音频 → 普通话文字"，而不是输出方言字）

## 评测指标

| 指标 | 说明 |
| --- | --- |
| CER（方言→普通话转写） | 主指标 |
| 方言识别正确率 | 模型是否能判断"这是粤语"还是"这是普通话" |
| 不支持方言的兜底行为 | 是硬报错？还是强行转成普通话？还是直接乱转？ |

## 特别观察项

- Qwen3-ASR 标称 22 种中文方言，实测粤语/四川话效果
- SenseVoice 支持粤语，但其他中文方言可能不支持
- Whisper large-v3 训练数据中粤语有一定覆盖，但普通话"塑料粤语"效果待验证
- Paraformer 主要是普通话，方言预期差

## 注意事项

- 方言转写的参考文本应该是**普通话书面语**，不是方言字（不要写"係咁先啦"作为参考，参考应是普通话"就这样吧"——但这个取决于目标产品需求，需要和用户确认）
- 实际上，ASR 产品对方言的处理有两种：(a) 直接输出方言字，(b) 翻译成普通话。本评测默认测 (a)，即"模型听到粤语后输出什么文字"，参考转写用该方言的书面表达
- 口音和方言分开统计，不要合并成一个"非标准普通话"指标
