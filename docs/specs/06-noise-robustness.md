# 06 · 吵杂与噪声环境抗干扰测试

> 维度编号：NOISE | 优先级：P0

## 背景

安静近场的 CER 大家都不错，真实使用场景才见真章。咖啡馆、马路、地铁、空调声——这些才是端侧 ASR 的主战场。本维度测模型在不同信噪比下的 CER 退化曲线。

## 测试集要求

### 基础音频

从 spec 02 中抽取 20 条普通话音频作为干净基底。

### 噪声叠加

用 FFmpeg/sox 给干净音频叠加不同类型和强度的噪声：

| 噪声类型 | SNR 档位 | 说明 |
| --- | --- | --- |
| 咖啡馆白噪/人声底噪 | 20dB / 10dB / 5dB | 轻度/中度/重度 |
| 马路交通噪 | 15dB / 5dB | |
| 地铁轰鸣 | 15dB / 5dB | 低频为主 |
| 空调/风扇稳态噪 | 20dB / 10dB | |
| 背景音乐（人声歌曲） | 10dB / 0dB | 最难，容易被歌声干扰 |

- 每条干净音频 × 每种噪声 × 每个 SNR = 一条新测试音频
- 总音频数：约 20 × 5 类 × 2-3 档 ≈ 200 条（可按需裁剪）

## 评测指标

| 指标 | 说明 |
| --- | --- |
| CER vs SNR 曲线 | 每个 SNR 档位的 CER |
| CER 退化幅度 | 从干净到 5dB 的 CER 增幅 |
| 吵杂环境抗造排名 | 同一 SNR 下谁的 CER 最低 |
| 幻觉率 | 噪声越大，模型越容易"听出"不存在的词（insertion 增多） |

## 特别观察项

- Whisper 在背景音乐下容易被歌声带跑（把歌词转写进结果）
- SenseVoice 有音频事件检测，可能能标注"检测到音乐"
- Qwen3-ASR 训练数据声称包含各种真实场景，预期抗噪与抗造表现较好

## 注意事项

- 噪声叠加用现成的噪声样本库（Freesound 等），不要自己录
- SNR 计算方式要一致（参考 ITU P.56），在 manifest 里记录实际 dB 值
- 不要做降噪后处理——我们评的是模型原生的抗造能力，不是"模型+降噪"的组合效果
- 同一干净基底在不同噪声下对比，控制变量
