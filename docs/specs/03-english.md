# 03 · 英文识别

> 维度编号：EN-CLEAN | 优先级：P0

## 背景

与 spec 02 对称，测英文干净条件下的 WER。Whisper 系列的英文训练数据最充分，预期表现远好于中文；Qwen3-ASR 也覆盖英文。这个维度回答"这个模型的英文基线怎么样"。

## 测试集要求

- **音频数量**：≥ 30 条
- **录音条件**：同 spec 02，安静近场
- **说话人**：至少 3 人（男女各半），标准美式/英式发音
- **内容覆盖**：
  - 短句问候："How are you?"
  - 日常对话："I'd like to book a table for two at 7 PM"
  - 技术讨论："The API endpoint returns 202 Accepted asynchronously"
  - 长段落（> 50 词）：一段科技文章朗读
- **含**：数字、缩写、专有名词（人名/地名/公司名）
- **参考转写**：人工听写，保留大小写和标点

## 注意事项

- Whisper 输出英文默认带标点，SenseVoice/Qwen3 也带；比对时按 spec 01 的标点归一化规则处理
- 缩写（API、CPU、GDP）和数字（"twenty dollars" → "$20"）单独观察
- 英文环境下 CER 不适用，统一报 WER
- 不要混入非英语的欧洲语言，那个由 Parakeet 等模型自己的语言覆盖范围决定
