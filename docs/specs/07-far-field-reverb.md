# 07 · 远场与混响

> 维度编号：FAR-FIELD | 优先级：P1

## 背景

手机近场说话和客厅里对智能音箱说话是两回事。远场 ASR 要面对低能量、强混响、 early reflection。这个维度模拟会议桌、客厅、车载场景。

## 测试集要求

### 方法 A：真实远场录制（首选）

- 在真实房间里录制：说话人距麦克风 1m / 2m / 3m
- 房间类型：普通办公室（混响约 200ms）、小会议室（混响约 400ms）
- 麦克风：手机内置麦、桌面麦克风各录一组

### 方法 B：人工混响模拟（补充）

- 用 pyroomacoustics 或 sox 对干净音频施加房间脉冲响应（RIR）模拟远场
- 模拟 1m / 3m / 5m 距离

- **音频数量**：≥ 20 条干净基底 × 3 种距离 = 60 条
- **内容**：同 spec 02 的日常对话

## 评测指标

| 指标 | 说明 |
| --- | --- |
| CER vs 距离 | 1m/3m/5m 各档 CER |
| 混响敏感度 | 近场 CER 和远场 CER 的差距 |
| 端点检测能力 | 长混响下是否会把尾巴误判成语音，或截断结尾 |

## 特别观察项

- Whisper 在远场下 CER 通常显著上升
- Paraformer 等面向会议场景的模型可能表现更好
- 是否需要前端 VAD（如 Silero VAD）作为前置处理——本维度默认不加，测原生能力

## 注意事项

- 远场录制时说话人不知道参考文本，用固定稿件朗读
- 房间混响时间（RT60）要记录在 manifest 里
- 这个维度和 spec 06 噪声不同：远场是混响+衰减，不是加性噪声
- 不要求测多人同时说话（那是 diarization 的事）
